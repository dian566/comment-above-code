One funny, painfully honest line imagining the comment a developer left
above fragile production code — the kind of line that is funny because
it is true.

## Entry

> // I knew this was wrong when I wrote it. The demo was in an hour, the raise was in a month, and it has run payroll ever since.

The joke lands on the last three words: a rushed hack, written under
deadline pressure for a demo, quietly became the code that pays everyone.

## How it works

Run `python3 main.py` and the program validates the line first — UTF-8,
non-blank, at most 200 characters — then writes it to `/output/entry.txt`
(127 characters, inside the gate). A house judge compares entries two at
a time and the sharpest, most honest laugh takes the pool.
